# VIP Salud Ocupacional — versión integrada

Esta entrega combina el contenido completo del HTML original con el diseño, los estilos y las interacciones del proyecto renovado.

## Cambios principales

- Todos los botones de certificados abren primero la pantalla empresarial integrada.
- La pantalla de certificados carga el portal oficial de Biofile dentro del sitio y conserva un acceso alterno en otra pestaña.
- Sección de descarga explicada en tres pasos.
- Cinco paquetes ocupacionales con sus componentes y modalidades.
- Tres plataformas especializadas: examen virtual, CRC y CIA.
- Portafolio completo de doce servicios con expansión interactiva.
- Mapa, cobertura, licencia y datos de contacto recuperados del HTML original.
- Formulario que prepara la solicitud y abre la línea comercial en WhatsApp.
- Política de tratamiento de datos completa y desplegable.
- Menú móvil, sección activa, animaciones suaves, acordeón y diseño responsive.
- Logo compacto suministrado por VIP, integrado en encabezado, portal, favicon y pie de página.

## Para probar

1. Extraiga el ZIP completo.
2. Abra la carpeta en Visual Studio Code.
3. Abra `index.html` con Live Server.
4. Si el navegador conserva una versión anterior, use `Ctrl + F5`.

No se debe separar `index.html` de `styles.css`, `script.js`, la carpeta `assets` ni la carpeta `descargas-biofile`.
