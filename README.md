# VIP Salud Ocupacional · Sitio web

Sitio institucional estático para consultar servicios de salud ocupacional, exámenes para conductores, telemedicina y el acceso al portal de certificados. La portada agrupa los servicios por necesidad y ofrece enlaces de orientación y contacto.

- [Inicio](index.html) reúne servicios, exámenes y accesos al portal.
- [Descargas BIOFILE](descargas-biofile/index.html) presenta el acceso a certificados.
- Las páginas de [privacidad](politica-de-privacidad/index.html), [términos y condiciones](terminos-y-condiciones/index.html) y [eliminación de datos](eliminacion-de-datos/index.html) documentan los canales de atención al titular.

Para una vista previa, abre `index.html` con un servidor estático local. `netlify.toml` define la configuración de publicación. Conserva las rutas de cada carpeta y comprueba los accesos al portal, el menú móvil y las páginas legales antes de publicar. El portal externo gestiona la consulta de certificados. Las pruebas del sitio deben hacerse con datos ficticios.
